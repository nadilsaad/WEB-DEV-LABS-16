# Week 02 Lab

## Objective
To learn how to use:
- Lists
- Tables
- Forms in HTML

## What was done
Created a 3-page website using HTML:
1. Home page
2. Timetable page
3. Contact page

The website includes:
- Ordered and unordered lists
- Timetable table using rowspan and colspan
- Contact form
- Student registration form using tables

## Challenges faced
- Understanding rowspan and colspan in tables
- Designing forms inside tables
- Linking all pages correctly

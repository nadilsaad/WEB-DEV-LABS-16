# LAB WEEK 4

## Objective

Apply CSS layout control techniques using:

* CSS Box Model
* CSS Positioning
* Float and Clear properties

The practical focuses on understanding how webpage elements are spaced, positioned, and arranged without using Flexbox or CSS Grid.

---

## What was done

Created a webpage demonstrating different CSS layout techniques with the following sections:

1. Fixed Header section
2. Sticky Navigation bar
3. Box Model demonstration section
4. Positioning section using relative and absolute positioning
5. Float-based two-column layout
6. Footer section cleared using `clear: both`

The webpage includes:

* Use of padding, margin, and borders
* Relative, absolute, fixed, and sticky positioning
* Float-based content layout
* Clear property to prevent overlapping
* External CSS file for styling and layout control

---

## CSS Concepts Applied

### Box Model

* `padding` for internal spacing
* `margin` for external spacing
* `border` for visible box boundaries

### Positioning

* `position: relative`
* `position: absolute`
* `position: fixed`
* `position: sticky`

### Float and Clear

* `float: left`
* `float: right`
* `clear: both`

---

## Challenges faced

* Understanding how float removes elements from normal document flow
* Preventing footer overlap using `clear`
* Positioning elements correctly using relative and absolute positioning
* Making the navigation bar sticky during scrolling
* Managing spacing using the CSS Box Model

# LAB WEEK 3

## Objective

Apply HTML structure and CSS styling using all three methods:

* Inline CSS
* Internal (Document Level) CSS
* External CSS

Also demonstrate the use of different CSS selector types.

## What was done

Created a single webpage using HTML and CSS with the following sections:

1. Header section (name and title)
2. Navigation menu with anchor links
3. About section containing a paragraph and image
4. Skills section using lists
5. Daily Routine section using an ordered list

The webpage includes:

* External CSS for main page styling
* Internal CSS for navigation and section heading styling
* Inline CSS applied to a few elements only
* Different CSS selectors including:

  * Element selectors
  * Class selectors
  * ID selectors
  * Group selectors
  * Descendant selectors
  * Pseudo-class selectors (:hover)

## Challenges faced

* Understanding the difference between inline, internal, and external CSS
* Applying different selector types correctly
* Styling the navigation menu using descendant selectors
* Using pseudo-classes such as hover effectively
* Linking the external CSS file properly

# Student Grade Calculator Web Application

## Objective

Develop a dynamic web application using HTML, CSS, and JavaScript that captures student scores, validates input, calculates grades, and updates the webpage instantly using DOM manipulation without page reload.

---

## What was done

Created a Student Grade Calculator Web Application with the following features:

1. User input field for entering student scores.
2. Calculate Grade button for processing results.
3. Input validation to ensure scores are valid.
4. Grade calculation using JavaScript control statements.
5. Dynamic result display using DOM manipulation.
6. Automatic input reset after calculation.

The application includes:

* User-friendly interface designed with HTML and CSS.
* Event handling using JavaScript.
* Real-time grade calculation without page refresh.
* Error handling for invalid inputs.
* Dynamic content updates using DOM methods.

---

## JavaScript Concepts Applied

### Event Handling

* `addEventListener()` for button click events.
* Capturing user input from form elements.

### Input Validation

* Checking whether input is a number.
* Ensuring score is between 0 and 100.
* Displaying error messages for invalid entries.

### Control Statements

* `if...else if...else` statements for grade determination.

### DOM Manipulation

* Selecting elements using `getElementById()`.
* Updating webpage content using:

  * `textContent`
  * `innerHTML`
* Displaying results dynamically without page reload.

### Form Reset

* Clearing the input field after displaying results.
* Allowing immediate entry of new scores.

## Grade Criteria

| Score Range | Grade |
| ----------- | ----- |
| 70 – 100    | A     |
| 60 – 69     | B     |
| 50 – 59     | C     |
| 40 – 49     | D     |
| Below 40    | F     |

---

## Expected Functional Behavior

1. User enters a score.
2. User clicks **Calculate Grade**.
3. System validates the input.
4. Grade is calculated based on the score.
5. Result is displayed instantly.
6. Input field is cleared for the next entry.
